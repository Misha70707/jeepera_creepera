## 2025-05-20 - [Documenting Early Stage Projects]
**Learning:** When documenting a repository that contains detailed architectural guides (like `CLAUDE.md`) but no implementation code, it is critical to explicitly label features as "Planned" or "Goals". Failing to do so can lead to confusion and accusations of hallucination, as reviewers may assume the documentation describes existing code.
**Action:** Always verify if code exists before writing feature lists. If the repo is empty, use phrasing like "Intended Architecture", "Planned Features", and "Project Roadmap".
