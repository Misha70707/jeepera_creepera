## 2025-11-14 - [Balancing DX and Security]
**Learning:** In highly sensitive ("Top Secret") projects, Developer Experience (DX) must be balanced with operational security. A clear but discreet README that acts as a secure gateway to internal documentation (like CLAUDE.md) is preferable to exposing detailed technical specs on the repository landing page.
**Action:** When working on sensitive repos, improve discoverability through links rather than detailed descriptions in public-facing files like README.md.
