## 2025-03-10 - Strict Version Control Exclusions for Top Secret Project
**Vulnerability:** The project repository lacked strict `.gitignore` exclusions for sensitive files like `.env`, `keys/`, Python execution artifacts, IDE configs, and MT5 binaries (`*.set`, `*.ex5`). This could result in accidental commit and leakage of critical credentials or compiled algorithms in a "Top Secret" codebase.
**Learning:** Due to the hybrid nature of this project (Python + MQL5 + JetBrains MPS tools), the standard boilerplate `.gitignore` was insufficient. Repositories handling algorithmic trading and sensitive configuration must enforce strict exclusion patterns for multi-stack environments out of the gate to maintain operational security.
**Prevention:** Implement comprehensive `.gitignore` blocks covering Secrets (`.env`, `keys/`), Artifacts (`__pycache__`, `venv`, `*.ex5`, `*.set`), Logs, and IDE configs as a baseline security requirement for all algorithmic trading repositories.
