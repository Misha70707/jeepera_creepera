## 2023-10-27 - SymbolInfo Overhead and Compilation Quirks
**Learning:** Frequent calls to `SymbolInfoDouble` (e.g., for `Ask`/`Bid`) in `OnTick` are a major performance bottleneck in high-frequency MQL5 strategies. Storing static properties (`Point`, `Digits`) in `OnInit` and updating dynamic properties using `MqlTick` struct saves significant overhead. Additionally, passing an `int` to `SymbolInfoInteger` causes compilation errors due to strict reference type mismatch; it demands a `long`. Statically caching `TickValue` is an anti-pattern for cross-currency pairs because it changes with conversion rates.
**Action:** Implement `CSymbolCache` to handle caching natively, completely replacing bare `SymbolInfo*` calls in critical paths. Always use `long` for `SymbolInfoInteger`. Retrieve `TickValue` dynamically or refresh it frequently.
