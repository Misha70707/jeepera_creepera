# 📱 Nexus Mobile Web - Use Nexus on Your Phone!

**Access Nexus from ANY device - phone, tablet, anywhere!** 🚀

---

## ⚡ QUICK START (2 Steps!)

### Step 1: Start the Server (30 seconds)

```bash
cd mobile_web
./launch_mobile.sh
```

### Step 2: Open on Your Phone

The script will show you an address like:
```
📱 http://192.168.1.100:5000
```

**Just open that on your phone!** 🎉

Once you open it on your phone:

1. Tap **⋮** (menu button)

3. Tap **"Add"**
4. **BOOM!** Nexus is now an app on your phone! 🎉

### On iPhone:
1. Tap **Share** button
2. Tap **"Add to Home Screen"**
3. Tap **"Add"**
4. **DONE!** Nexus icon on your home screen! 🚀

## 🆘 Troubleshooting

### Can't Access from Phone?

**Check WiFi:**
```bash
# Make sure phone and computer on same WiFi
```

**Find Your IP:**
```bash
# Linux/Mac
hostname -I

# Windows
ipconfig
```

**Firewall:**
```bash
# Allow port 5000
sudo ufw allow 5000
```

### Server Won't Start?

**Install Flask:**
```bash
pip install flask flask-cors
```

**Check Ollama:**
```bash
ollama serve
```
